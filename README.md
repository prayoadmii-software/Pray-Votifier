# **Pray Votifier**

**Yup! Another Votifier Plugin :D**

---

### **What Is Votifier?**

**Votifier Is A Vote-For-Reward Recover System**

---

### **What Is Vote-For-Reward?**

**There's Many Minecraft Server Lists Website That Support Voting System Like [Minecraft.Buzz](https://minecraft.buzz/) Or [Eaglercraft Servers List](https://servers.eaglercraft.com/)**

**Vote-For-Reword Is That Players Go To Websites Like [Pray SMP On Minecraft.Buzz](https://minecraft.buzz/vote/pray-smp) And Enter Your Minecraft Username And Vote**

**Then Vote Request Will Go To Server Plugin Like This Plugin And Then Server Need To Process Request Like**

- **Reward Player Some Item**
- **Give Players A Rank**

**And Many More**

---

### **How Is This Plugin Different From Other Votifier Plugins?**

1. **Easy To Setup - No 500 Lines Configs No Plugins Hooking Just Write List Of Commands Into `command.yml`**
2. **Proxy Support (Coming Soon) - Add Proxy Like Velocity Supporting Mean You Can Execute Proxy Commands Or Umm... Actually I Can't Write It All Right Now Because We Still Working On It**

### **Good Point**

- **Compatable With All Standard Votifier API (Both V1 And V2 - Configure In Config)**

---

### **Please Note**

- **Votifier Is Not HTTP API You Need A Raw TCP Port Open**
- **This Plugin Require [CommandAPI Plugin](https://modrinth.com/plugin/commandapi) To Work**
